TikZ Evolution

One alpaca, every generation

Every model below received the exact same prompt — draw a single cartoon alpaca in TikZ — with no temperature override and no other variation. Each family is ordered left-to-right by release date, so the progression (and the drift) of a fixed visual task becomes visible across a model lineage.

The Prompt & Methodology ~ ~ ~ ~ ~ ~ ~
System prompt

You are an expert TikZ illustrator. Emit complete, compilable, self-contained LaTeX only.

User prompt — identical for every model, every family

Create a complete, compilable LaTeX document using the standalone documentclass and ONLY the tikz package (libraries: backgrounds, decorations.pathmorphing, snakes, calc are allowed). The picture must draw a SINGLE cute cartoon alpaca, centered, fluffy light-cream body, long neck, small head with two ears and a fluffy tuft on top, four little legs, a friendly face. Use bright pleasing colors and clean thick dark outlines, on a soft plain background. Do NOT include any text, labels, captions, watermarks, or other animals. Do NOT use \includegraphics or external images. Output ONLY the raw LaTeX source inside one ```latex code fence, nothing else before or after.

How this page was made
  • One fixed prompt — every model, in every family, received the byte-for-byte same alpaca prompt. The only variable is the model itself.
  • Grouped by family, ordered by release date — each row runs oldest → newest, so you see a lineage evolve and drift, not a cross-vendor shootout.
  • Full token budget — no generation was capped; each model got its full allowed max output tokens.
  • Temperature guarded — models that reject non-default temperature omit the field entirely.
  • Unedited output — standalone TikZ → Tectonic compile → PNG raster. What you see is exactly what each model emitted.
