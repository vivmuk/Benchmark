TikZ Evolution

One alpaca, every generation

Every model below received the exact same prompt — draw a single cartoon alpaca in TikZ — with no temperature override and no other variation. Each family is ordered left-to-right by release date, so the progression (and drift) of a fixed visual task becomes visible across a model lineage.

Prompt & Methodology

→ what every model in every family saw →
system prompt

“You are an expert TikZ illustrator. Emit complete, compilable, self-contained LaTeX only.”

user prompt (identical for all)

“Create a complete, compilable LaTeX document using the standalone documentclass and ONLY the tikz package (libraries: backgrounds, decorations.pathmorphing, snakes, calc are allowed). The picture must draw a SINGLE cute cartoon alpaca, centered, fluffy light-cream body, long neck, small head with two ears and a fluffy tuft on top, four little legs, a friendly face. Use bright pleasing colors and clean thick dark outlines, on a soft plain background. Do NOT include any text, labels, captions, watermarks, or other animals. Do NOT use \includegraphics or external images. Output ONLY the raw LaTeX source inside one ```latex code fence, nothing else before or after.”

methodology
  • § Every model in every family received the same single-alpaca prompt — no per-model variation. The only variable is the model itself.
  • § Models are grouped by family and ordered by release date (oldest → newest) within each family — this shows evolution, not a cross-family ranking.
  • § Each model was given its full allowed max output tokens (model_spec.maxCompletionTokens) — never capped, so no finish_reason=length truncation.
  • § Temperature-locked models (GPT-5.6 Luna, GPT-6 Astra) omit the temperature field entirely.
  • § Pipeline: self-contained standalone TikZ → compiled with Tectonic → rasterized to PNG via PyMuPDF at 3×.
  • § Zero post-processing of the generated LaTeX — what you see is exactly what the model emitted (only undefined-colour names are auto-supplied so a file can compile).
