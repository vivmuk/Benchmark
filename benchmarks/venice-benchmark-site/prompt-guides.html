Prompt Guides

Prompting patterns for the latest models — with what changed from the previous generation. Source: Prompting Claude Opus 5.5 (Anthropic docs) and the Claude Opus 5 prompting guide.

Anthropic — Claude

Latest Claude Opus 5.5

  • Thinking is always on — rejects thinking: disabled. Omit it or use adaptive.
  • Default effort = medium (Opus 5 defaulted to high). Set it explicitly.
  • Effort calibration: start medium → drop to low to cut latency/cost → step up to high/xhigh only when measured.
  • Long agentic turns: max_tokens=128000 (thinking counts toward it).
  • ~30% faster + fewer output tokens than Opus 5.
  • Progress updates come back as thinking blocks (empty by default) — set display:"updates".
  • Unattended agents: a text-only end_turn is a report, not completion — keep working + a checklist.
  • Don't ask it to reproduce internal reasoning → reasoning_extraction refusal. Use display:"summarized".
  • New safeties: biology (same as Fable 5.1), cybersecurity, reasoning_extraction.
  • Frontend looks generic without explicit design tokens.

Previous Claude Opus 5

  • Thinking on by default; disabled accepted at high or below.
  • Default effort = high.
  • Verbose by default — needs an explicit conciseness instruction.
  • Strong agentic coding when given the full spec up front.

Claude Fable 5.1

  • Shares 3 breaking changes with Opus 5.5: thinking can't be disabled; forced tool use errors; thinking blocks tied to model+conversation.
  • Same new biology safeguard as Opus 5.5.

Key difference: Opus 5.5 flips thinking to always-on, lowers the default effort from high→medium, changes how progress/tool-call text is returned, and adds end_turn-report + reasoning_extraction/biology safeguards. Opus 5 prompts still work; just set effort explicitly and add an unattended-agent continuation instruction.

OpenAI — GPT-6.x vs GPT-5.6

Latest GPT-6.1 Sol · GPT-6 Sol / Luna / Astra / Astra Pro

  • GPT-6.1 Sol is the current flagship (VivIndex 86.0, #18) — a big step over GPT-6 Sol (75.8).
  • GPT-6 Astra / Astra Pro — top reasoning tier.
  • GPT-6 Luna — low-cost / fast tier.
  • Reasoning on by default (often "high") — calibrate effort down for latency-sensitive work; generous max_tokens for long agentic runs.
  • Prefer 6.1 Sol / Astra for knowledge + coding; Luna for cheap/fast.

Previous GPT-5.6 Sol / Luna / Terra

  • Superseded by the GPT-6.x line.
  • Seed prompts as-is — they perform well; move quality-sensitive work to GPT-6.1 Sol / Astra.

Copyable instruction guide

Paste this into your agents' prompt optimizer (or their system prompt) to make them prompt these models correctly.

## UNIVERSAL RULES (all reasoning models)
1. Set reasoning `effort` explicitly every call; default to the model's documented default.
2. `max_tokens` must leave room for hidden thinking — use the model's max for long agentic turns (Anthropic: 128000).
3. A text-only end-of-turn with no tool call is a progress REPORT, not completion — continue if open tasks remain (cap 2-3 auto-continuations).
4. Never instruct a reasoning model to "show your chain-of-thought"; read summarized thinking via the API instead.
5. Give tools for visual/diagram work rather than asking it to think through pixels.
6. Supply explicit frontend design tokens when generating UI.

## Claude Opus 5.5 (latest)
- Thinking always on: omit `thinking`, or send `{"type":"adaptive"}`. Never `disabled`.
- effort = `medium` (default); drop to `low` for speed, step to `high/xhigh/max` only when measured.
- max_tokens=128000 for long agentic coding.
- Progress updates are `thinking` blocks (empty by default) → set `display:"updates"`.
- Unattended: add "keep working, don't end the turn with a summary" + an open-items checklist; auto-continue ≤ 3×.
- Don't ask for internal reasoning in the reply (reasoning_extraction refusal) → `display:"summarized"`.
- Frontend: give explicit colors/fonts/layout.

## Claude Opus 5 (previous)
- thinking default; `disabled` OK at ≤high. effort default `high`.
- Verbose → add a conciseness instruction. Full spec up front, leave it to run.

## Claude Fable 5.1 / Sonnet 5.5
- thinking always-on (Fable 5.1); medium effort; same new safeties.

## GPT-6.1 Sol / GPT-6 Sol / Luna / Astra (latest)
- Reasoning on, effort "high" default — calibrate down. 6.1 Sol for quality, Luna for cheap/fast.
- Generous max_tokens for long agentic work.

## GPT-5.6 Sol / Luna / Terra (previous)
- Superseded; prompts port as-is.
