How we score

Every benchmark is run with fixed prompts, default sampling, and transparent heuristics. Scores are reproducible and auditable.

01 · Intent Understanding

Models receive ambiguous, underspecified prompts. Points for clarifying questions, structured proposals, and explicit uncertainty before assuming details.

02 · One-Shot UI Generation

Models must emit a single self-contained HTML file. Scored on visual polish, semantic structure, accessibility, responsiveness, and whether it runs without edits.

Models generate a playable Canvas game in one shot. Scored on physics plausibility, control responsiveness, collision detection, game states, particle/sound effects, and responsive design.

03 · Startup in a Weekend

Models receive a tight MVP brief for an AI contract-review SaaS. Points for system architecture, concrete database schema, API endpoints, auth strategy, AI pipeline, deployment stack, day-by-day schedule, cost estimate, risk/mitigations, and explicit out-of-scope boundaries.

04 · VivIndex Composite

Weighted average of five tracks. Startup 25%, Intent 20%, Value Density 20%, Reverse-Prompt 20%, UI 15%. Missing benchmarks are labelled and weights are renormalized rather than scored as zero.

05 · Pharma tracks

Drug-drug interaction identification and regulatory guideline comprehension are scored and charted for domain fitness. They are not folded into VivIndex so the composite remains comparable over time.

06 · Value Density @1K

Identical clinical JSON task, max_tokens=1024. Heuristic checklist on schema validity, required fields, and clinical correctness. Secondary metrics: score/1K tokens and score/USD. Length cannot inflate the primary score.

07 · Reverse-Prompt Vision

Complex image from nano-banana-2. Models receive only the image + reconstruct-prompt instruction. A separate judge compares the reconstruction to the hidden source prompt via a fixed attribute checklist. Non-vision models are marked skipped.

08 · Full protocol

Exact prompts, scoring math, and non-claims are published on the Experimental Design page — the lab notebook for this suite.
