The distillate

Seven lessons that transfer.

Everything the eight teardowns taught, compressed into patterns you can carry into any AI project.

LESSON 01

Prompt economy is real

The smallest prompt (Perplexity, ~2K tokens) works because it only injects the product delta. Every unnecessary instruction dilutes the ones that matter.

→ Perplexity · Edition 08
LESSON 02

Structure beats prose

Claude Opus scopes rules with nested XML; GPT-5.6 resolves conflicts with an ordered refusal cascade. When instructions collide, structure is the referee.

→ Opus · GPT-5.6 · Gemini
LESSON 03

Think in channels, not messages

Codex separates private reasoning, visible tool calls, and the final answer. Give the model a scratchpad.

→ Codex · Edition 07
LESSON 04

Memory is architecture, not prompting

Copilot CLI's three-layer memory with REM consolidation and Cursor's auto-injected context: persistent memory comes from structures, not from asking nicely.

LESSON 05

A GPT orchestrator shipping Anthropic sub-agents; a rescue agent that calls Claude Code. Specialized workers, strict boundaries.

Codex gates critical actions on undefined “high-impact decisions.” Vague thresholds are the #1 failure source in every prompt we read.

Citation contracts, channel systems, rendering specs: winning products specify the interface between model and product.

For everyone

The plain-language field guide.

No jargon required. Six habits distilled from how the best AI teams write their instructions.

1 · Be specific, not polite

Precision gets results; politeness wastes tokens.

✗ “Summarize this briefly” ✓ “Summarize in under 80 words, 3 bullets, no intro”

2 · Give every rule its own box

Labeled sections resolve conflicts that flat paragraphs can't.

✗ “Casual but professional, detailed but short” ✓ “TONE: casual. LENGTH: short. AUDIENCE: engineers.”

3 · Ask for thinking space

OpenAI's agent prompt gives the AI a private scratchpad first. Answers get measurably better.

✗ “What's wrong with this code?” ✓ “First list what you know, what's missing. Then answer.”

4 · Build memory, don't ask for it

Keep a profile block and paste it in, like Copilot's session store does.

✗ “Remember my preferences” ✓ “CONTEXT: I'm a lawyer. Precise terms. No bullets.”

5 · Split big jobs into roles

Scout, critic, executor. Three passes beat one mega-prompt.

✗ One giant prompt ✓ Pass 1: outline. Pass 2: critique. Pass 3: final.

6 · Numbers are enforceable

Adjectives aren't. If it matters, attach a number.

✗ “Keep it concise” ✓ “Max 150 words. Max 3 sources. Nothing older than 2024.”
