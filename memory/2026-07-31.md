### Key technical learnings
1. **BE CAREFUL**: `railway up` CLI hangs at "Indexing..." on the large (~422MB) workspace and is NOT the right path. Use `git push` → auto-deploy instead.
2. **The gateway's real API keys live in `~/.openclaw/service-env/ai.openclaw.gateway.env`** as both VENICE_API_KEY and VENICE_INFERENCE_KEY. Two lines at EOF are NOT `export`-prefixed — regex must allow optional `export `.
3. Chat auth failures earlier were because my shell had a literal `***` placeholder, not the real key. Real key authenticates both `/models` and `/chat/completions` fine.
4. Venice image generation: POST to `https://api.venice.ai/api/v1/images/generations` with `{model, prompt, size, n, hide_watermark}`. gpt-image-2 works. Returns b64_json or url.
5. Created `.railwayignore` at workspace root to exclude .venv, node_modules, __pycache__, .git, etc.
6. Universe: site board excludes brick_breaker_realism from display AND from VivIndex weights. Weights: intent-understanding 0.20, one-shot-ui 0.15, startup-in-a-weekend 0.25, value-density 0.20, reverse-prompt-vision 0.20.
