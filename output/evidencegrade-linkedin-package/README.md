# EvidenceGrade LinkedIn Publishing Package

## Contents
- `LINKEDIN_POST.md` — ready-to-publish LinkedIn copy
- `CAROUSEL_COPY_AND_PUBLISHING_GUIDE.md` — slide narrative, claim discipline, alt text, and source
- `carousel-images/` — five publication-order carousel slides

## Recommended LinkedIn setup
- Upload carousel images in numerical order.
- Paste the body from `LINKEDIN_POST.md`.
- Use the source URL in the post body or first comment according to your normal posting practice.
- Preserve the final CTA card as slide 5.
